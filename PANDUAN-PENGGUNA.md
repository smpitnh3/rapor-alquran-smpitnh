# Panduan Pengguna

# Aplikasi Rapor Al-Qur’an SMPIT Nur Hikmah

Panduan ini dibuat untuk membantu admin dan guru menggunakan aplikasi Rapor Al-Qur’an, mulai dari login, mengatur data, input capaian, melihat preview rapor, hingga membuat file PDF dan Excel.

---

## 1. Login Aplikasi

1. Buka link aplikasi Rapor Al-Qur’an.
2. Masukkan email dan password.
3. Klik tombol **Masuk**.
4. Setelah berhasil login, pengguna akan diarahkan ke dashboard.

Jika login gagal, periksa kembali email dan password yang digunakan.

---

## 2. Jenis Pengguna

Aplikasi memiliki dua jenis pengguna utama.

### Admin

Admin dapat mengakses seluruh fitur aplikasi, seperti:

- Melihat semua data siswa
- Mengatur identitas sekolah dan periode aktif
- Melihat semua kelas dan halaqoh
- Menginput capaian semua siswa
- Melihat semua preview rapor
- Membuat PDF dan Excel untuk semua siswa

### Guru

Guru hanya dapat mengakses data sesuai halaqoh yang diampu, seperti:

- Melihat siswa di halaqohnya
- Menginput capaian siswa di halaqohnya
- Melihat preview rapor siswa di halaqohnya
- Membuat PDF dan Excel sesuai akses halaqohnya

---

## 3. Dashboard

Halaman **Dashboard** menampilkan ringkasan data aplikasi.

Informasi yang tersedia antara lain:

- Jumlah siswa
- Jumlah kelas
- Jumlah halaqoh
- Jumlah capaian yang sudah diinput
- Ringkasan capaian per halaqoh
- Daftar siswa yang membutuhkan perhatian

Gunakan filter di bagian atas untuk melihat data berdasarkan tahun ajaran, periode, kelas, atau halaqoh tertentu.

---

## 4. Pengaturan

Halaman **Pengaturan** digunakan untuk mengatur data umum aplikasi.

Admin dapat mengatur:

- Nama sekolah
- Nama aplikasi
- Alamat sekolah
- Email admin
- Tahun ajaran aktif
- Periode aktif
- Label semester
- Target ziyadah default
- Target murojaah default
- Jumlah hari efektif
- Tempat dan tanggal titimangsa rapor

Setelah mengubah data, klik tombol **Simpan Pengaturan**.

Perubahan pengaturan akan mempengaruhi halaman input capaian, preview rapor, dan generate file.

---

## 5. Kelas & Halaqoh

Halaman **Kelas & Halaqoh** digunakan untuk melihat data kelas dan halaqoh.

Di halaman ini pengguna dapat melihat:

- Nama kelas
- Level kelas
- Wali kelas
- Jumlah siswa per kelas
- Nama halaqoh
- Guru halaqoh
- Jumlah siswa per halaqoh

Admin dapat membuka data kelas dan halaqoh di Google Sheets melalui tombol yang tersedia, jika link sudah diatur di pengaturan.

---

## 6. Data Siswa

Halaman **Data Siswa** digunakan untuk melihat daftar siswa.

Informasi yang ditampilkan:

- NIS
- Nama siswa
- Kelas
- Halaqoh
- Status siswa

Pengguna dapat menggunakan pencarian dan filter untuk menemukan siswa tertentu.

Guru hanya akan melihat siswa sesuai halaqoh yang diampu.

---

## 7. Input Capaian Per Siswa

Halaman **Input Capaian** digunakan untuk menginput capaian satu siswa.

Langkah penggunaan:

1. Buka halaman **Input Capaian**.
2. Pilih tahun ajaran, periode, kelas, dan halaqoh.
3. Cari siswa yang akan diinput.
4. Klik tombol **Input** atau **Edit** pada baris siswa.
5. Isi data capaian.
6. Klik **Simpan Capaian**.

Data yang diisi meliputi:

- Bulan laporan
- Target ziyadah
- Target murojaah
- Hari efektif
- Capaian hafalan
- Status hafalan
- Capaian murojaah
- Status murojaah
- Target dan capaian kedisiplinan
- Status kedisiplinan
- Catatan hafalan
- Catatan tahsin
- Catatan kedisiplinan
- Wali kelas
- Guru Al-Qur’an
- Tempat dan tanggal rapor

---

## 8. Input Massal

Halaman **Input Massal** digunakan untuk menginput capaian banyak siswa sekaligus dalam bentuk spreadsheet.

Langkah penggunaan:

1. Buka halaman **Input Capaian**.
2. Klik tombol **Input Massal**.
3. Pilih tahun ajaran, periode, kelas, dan halaqoh.
4. Isi data capaian pada tabel spreadsheet.
5. Klik **Validasi** untuk memeriksa data.
6. Jika data sudah valid, klik **Simpan Semua**.

Kolom catatan dapat diedit dengan cara double click pada kolom catatan.

Kolom catatan yang tersedia:

- Catatan Hafalan
- Catatan Tahsin
- Catatan Disiplin

Setelah double click, akan muncul editor catatan. Isi catatan lalu klik **Simpan Catatan**.

---

## 9. Preview Rapor

Halaman **Preview Rapor** digunakan untuk melihat tampilan rapor sebelum dicetak atau dibuat PDF.

Langkah penggunaan:

1. Buka halaman **Preview Rapor**.
2. Pilih tahun ajaran dan periode.
3. Pilih kelas, halaqoh, dan siswa.
4. Preview rapor akan tampil otomatis.
5. Gunakan tombol **Sebelumnya** dan **Berikutnya** untuk berpindah antar siswa.
6. Klik **Print** jika ingin mencetak langsung dari browser.

Rapor ditampilkan dalam format A4.

---

## 10. Generate File

Halaman **Generate File** digunakan untuk membuat PDF atau Excel.

Jenis file yang dapat dibuat:

- PDF rapor per siswa
- PDF gabungan
- Excel rekap capaian

Target generate dapat berupa:

- Satu siswa
- Satu halaqoh
- Satu kelas

Langkah penggunaan:

1. Buka halaman **Generate File**.
2. Pilih tahun ajaran dan periode.
3. Pilih mode generate.
4. Pilih jenis file.
5. Pilih target siswa, halaqoh, atau kelas.
6. Periksa estimasi jumlah file.
7. Klik tombol **Generate PDF** atau **Generate Excel**.

Setelah file dibuat, riwayat generate akan tampil di tabel riwayat.

---

## 11. Dark Mode

Aplikasi mendukung mode terang dan gelap.

Untuk mengganti mode:

1. Klik tombol tema di topbar.
2. Mode akan berganti antara terang dan gelap.
3. Pilihan mode akan disimpan otomatis di browser.

Catatan: tampilan kertas rapor tetap putih meskipun aplikasi berada dalam dark mode.

---

## 12. Tampilan Mobile

Aplikasi dapat digunakan di perangkat mobile.

Pada layar kecil:

- Sidebar berubah menjadi drawer.
- Klik tombol menu untuk membuka sidebar.
- Setelah memilih menu, sidebar akan tertutup otomatis.
- Tabel dapat digeser ke samping jika kolom terlalu banyak.

---

## 13. Pesan Error Umum

### Koneksi internet terputus

Jika muncul pesan koneksi internet terputus, sambungkan kembali internet lalu ulangi proses.

### Data gagal disimpan

Jika data gagal disimpan:

1. Pastikan koneksi internet aktif.
2. Pastikan backend Google Apps Script aktif.
3. Coba simpan ulang.
4. Jika masih gagal, hubungi admin aplikasi.

### Data tidak muncul

Jika data tidak muncul:

1. Cek filter tahun ajaran dan periode.
2. Pastikan data siswa aktif.
3. Pastikan siswa sudah masuk kelas dan halaqoh yang benar.
4. Untuk guru, pastikan akun guru sudah terhubung ke halaqoh yang benar.

---

## 14. Tips Penggunaan

- Simpan pengaturan terlebih dahulu sebelum input capaian.
- Pastikan periode aktif sudah benar.
- Gunakan input massal jika ingin menginput banyak siswa sekaligus.
- Gunakan preview sebelum generate PDF.
- Periksa ulang catatan sebelum membuat file rapor.
- Gunakan Excel rekap untuk arsip atau evaluasi internal.

---

## 15. Alur Kerja yang Disarankan

Alur kerja terbaik:

1. Admin memastikan data tahun ajaran, periode, kelas, halaqoh, siswa, dan guru sudah benar.
2. Admin mengatur periode aktif di halaman Pengaturan.
3. Guru menginput capaian siswa.
4. Guru atau admin mengecek Preview Rapor.
5. Admin atau guru membuat PDF rapor.
6. Admin membuat Excel rekap jika diperlukan.
7. File rapor dibagikan atau dicetak sesuai kebutuhan.

---

## 16. Bantuan

Jika terjadi kendala, hubungi admin aplikasi atau pengelola data sekolah.

Sertakan informasi berikut saat melaporkan masalah:

- Nama pengguna
- Role pengguna
- Halaman yang bermasalah
- Tindakan yang dilakukan sebelum error
- Screenshot error jika ada
- Waktu kejadian
